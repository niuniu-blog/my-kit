# MyKit 设计文档：截图模块第二期 —— 标注工具

日期：2026-09-21
状态：已实现（实现计划：`docs/superpowers/plans/2026-09-21-mykit-annotation.md`）
前置：`2026-09-21-mykit-screenshot-design.md`（截图第一期，已实现；其 §8 记录了实现后的变更：快捷键 ⇧⌘A 可自定义、识别文字 / 翻译时遮罩不关闭等）

## 1. 目标与范围

在截图遮罩的工具条上增加标注工具：框选区域后可以在上面画标注，再复制 / 保存 / 贴图。

### 已确认的决策

| 项 | 决策 |
|---|---|
| 工具 | 九种：方框、椭圆、箭头、直线、画笔、荧光笔、文字、马赛克、序号 ①②③；外加撤销 / 重做 |
| 可编辑性 | **只能撤销重画**。画好的标注不能再选中、移动、改大小 |
| 颜色 / 粗细 | 6 种预设颜色（红 黄 绿 蓝 黑 白）+ 3 档粗细（细 中 粗）；默认红、中；记住上次的选择 |
| 马赛克 | 拖出矩形，矩形内变成像素方块（不做模糊效果） |
| 输出 | 复制 / 保存 / 贴图 = 带全部标注的图；识别文字 / 翻译 = 原图 + **仅马赛克**（被遮住的内容不会被识别，其他标注不干扰识别） |
| 技术方案 | 矢量标注列表：每个标注是一条数据，屏幕上实时绘制，导出时合成。撤销 = 去掉最后一条 |

### 不做

选中 / 移动 / 修改已画好的标注、自定义任意颜色、模糊效果、给贴图做标注、标注模板、工具的单键快捷键。

## 2. 用户可见的行为

### 2.1 工具条

```
┌───────────────────────────────────────────────────────────────────────────┐
│ ▭  ◯  ↗  ／  ✎  🖍  T  ▦  ①  │  ↶  ↷  │  📌贴图  🔤识别文字  💾保存  📋复制  ✕ │
└───────────────────────────────────────────────────────────────────────────┘
  选中某个工具后，工具条下方多出一行样式栏：
┌──────────────────────────────────────────┐
│ ● ● ● ● ● ●    细  中  粗                │
└──────────────────────────────────────────┘
```

- 工具按钮用 SF Symbols 图标，鼠标悬停显示中文名称（tooltip）。选中的工具高亮。
- 点一个工具 = 选中；再点一次 = 取消选中。同一时间最多一个工具。
- 撤销 / 重做按钮在无可撤销 / 无可重做时置灰。
- 样式栏只在有工具选中时显示；马赛克工具选中时样式栏只显示粗细（= 方块大小），不显示颜色。
- 工具条变宽后仍按第一期的规则摆放（选区下方右对齐 → 上方 → 选区内），并夹在屏幕内；样式栏紧贴工具条下方左对齐，下方放不下时放到工具条上方。

### 2.2 各工具

所有标注只能画在选区内：起点必须在选区内；拖出选区的部分被裁掉（绘制和导出时都以选区为裁剪区域）。坐标以**选区左上角为原点、单位 pt** 记录。

| 工具 | 交互 | 样式 |
|---|---|---|
| 方框 | 拖出矩形。`Shift` = 正方形 | 描边，线宽 2 / 4 / 6 pt |
| 椭圆 | 拖出外接矩形。`Shift` = 正圆 | 同上 |
| 直线 | 起点拖到终点。`Shift` = 吸附到 0° / 45° / 90°… | 同上，圆头 |
| 箭头 | 同直线，终点带实心箭头 | 线宽同上；箭头长 = 线宽 × 4 + 6，夹角 ±28° |
| 画笔 | 自由涂画 | 线宽同上，圆头圆角 |
| 荧光笔 | 自由涂画。`Shift` = 起点到当前点的直线 | 所选颜色 40% 不透明度；线宽 12 / 18 / 24 pt；方头 |
| 文字 | 点一下 → 出现输入框（支持中文输入法、回车换行）→ 点别处 / `Esc` 完成；空内容不产生标注 | 字号 14 / 20 / 28 pt，系统字体 medium，所选颜色 |
| 马赛克 | 拖出矩形 | 方块边长 8 / 12 / 18 pt（按粗细档位） |
| 序号 | 点一下放一个；编号 = 已有序号标注的个数 + 1（撤销后自动回退） | 实心圆，直径 22 / 28 / 36 pt，所选颜色；数字白色（所选颜色为白或黄时数字为黑色） |

拖动距离小于 3pt 的方框 / 椭圆 / 直线 / 箭头 / 马赛克视为误点，不产生标注。画笔 / 荧光笔少于 2 个点同样忽略。

### 2.3 撤销 / 重做

- `⌘Z` 撤销最后一个标注；`⇧⌘Z` 重做。产生新标注时清空重做栈。
- 文字输入框处于编辑状态时，`⌘Z` / `⇧⌘Z` 交给输入框自己（撤销打字）。

### 2.4 取消键的层级（`Esc` / 右键）

1. 正在输入文字 → 完成文字输入（右键同）。
2. 有工具选中 → 取消选中工具。
3. 否则同第一期：有选区 → 清除选区（**连同全部标注和重做栈**），回到窗口识别状态；没有选区 → 退出截图。

全局保底退出（截图中再按一次截图快捷键）不变。

### 2.5 选区锁定

有工具选中**或**已有标注时：选区不能移动 / 改大小，选区外拖动也不会开始新选区，手柄不显示，双击选区不触发复制（避免画图时误触发）。标注全部撤销且没有工具选中时恢复第一期的全部选区操作。

### 2.6 输出

| 操作 | 用的图 |
|---|---|
| 复制 / 保存 / 贴图 | 选区裁剪图 + 全部标注（按像素倍数渲染，Retina 下清晰） |
| 识别文字 / 翻译 | 选区裁剪图 + 仅马赛克标注 |

## 3. 架构

全部在 `ScreenshotModule` 内，不改 `Core` 与其他模块。

| 单元 | 职责 | 测试 |
|---|---|---|
| `AnnotationTool` | 枚举九种工具：`rectangle, ellipse, line, arrow, pen, highlighter, text, mosaic, number`；中文名、SF Symbol 名 | ✅ |
| `AnnotationColor` / `AnnotationSize` | 6 色（含 RGB 值、序号数字用黑还是白）、3 档；各工具的线宽 / 字号 / 直径 / 方块边长换算 | ✅ |
| `Annotation` | 值类型：`kind`（带几何数据的枚举）+ `color` + `size`。几何用选区内坐标（左上原点，pt） | ✅ |
| `AnnotationGeometry` | 纯函数：`Shift` 约束（正方形、角度吸附）、箭头三角形顶点、由两点求规范化矩形 | ✅ |
| `AnnotationModel` | 纯状态机：`tool`、`color`、`size`、`items`、`redoStack`、`inProgress`；`mouseDown/Dragged/Up(at:shift:)`（选区内坐标 + 选区尺寸）；`placeText(_:at:)`；`undo/redo`；`canUndo/canRedo`；`reset()`；`locksSelection`（有工具或有标注）；序号计数 | ✅ |
| `AnnotationRenderer` | `draw(_ items:, inProgress:, in: CGContext, selectionSize:, scale:, baseImage:)`：坐标系为左上原点；马赛克从 `baseImage`（选区裁剪图）取像素做像素化。`flatten(base:, items:, pointSize:, scale:) -> CGImage?` 用于导出；`flatten(..., onlyMosaic: true)` 用于 OCR | ✅ 渲染到位图后检查像素：方框边上是所选颜色、内部未变；马赛克区域每个方块内颜色一致、区域外未变；裁剪生效；2× 尺寸正确 |
| `AnnotationSettings` | UserDefaults：`screenshot.annotation.color`、`screenshot.annotation.size` | ✅ |
| `OverlayView` 改动 | 选区锁定时把鼠标事件转给 `AnnotationModel`（换算成选区内坐标）；`draw` 里在选区内调用 `AnnotationRenderer`；文字工具的输入框（`NSTextView` 子视图，透明背景）；光标：工具选中时选区内为十字 | 手动 |
| `CaptureToolbar` 改动 | 增加工具按钮组、撤销 / 重做、样式栏；状态由 `AnnotationModel` 驱动 | 手动 |
| `OverlayPanel` 改动 | 文字输入框是第一响应者时，键盘事件正常下发给它（第一期是"遮罩吞掉所有按键"）；`⌘Z` / `⇧⌘Z` 映射到撤销 / 重做 | `OverlayKeyMap` ✅ |
| `CaptureResult` 改动 | `make` 接收标注列表：`image` = 带标注的图，另带 `ocrImage` = 仅马赛克的图 | ✅ |
| `SelectionModel` 改动 | 增加 `isLocked`：为 true 时忽略会改变选区的输入 | ✅ |

### 坐标

- `SelectionModel` / `OverlayView` 用屏内坐标（左上原点，pt）。传给 `AnnotationModel` 前减去选区原点 → 选区内坐标。
- `AnnotationRenderer` 在 `CGContext` 里先翻转成左上原点、再按 `scale` 放大，之后所有几何直接用选区内坐标。屏幕绘制时 `scale = 1` 并平移到选区原点；导出时 `scale` = 像素倍数。

### 轻量

标注是几十字节的值类型；马赛克只在绘制 / 导出时计算（屏幕绘制时对每个马赛克标注缓存一次像素化结果，遮罩结束即释放）；不新增常驻对象、定时器或线程。

## 4. 错误处理

| 情况 | 处理 |
|---|---|
| 导出合成失败（位图上下文创建失败） | 退回不带标注的裁剪图，Toast 提示「标注未能合成，已输出原图」 |
| 文字输入框内容为空或只有空白 | 不产生标注 |
| 马赛克矩形超出选区 | 先与选区求交，再像素化 |

## 5. 测试

自动化（Swift Testing）：上表标 ✅ 的全部单元。重点用例：每种工具一次完整的按下-拖动-松开产生正确的标注；误点不产生标注；`Shift` 约束；起点在选区外不开始；拖出选区的终点不被夹取但渲染被裁剪；撤销 / 重做 / 新标注清空重做栈；序号在撤销后回退；`locksSelection`；`reset`；渲染像素检查；`onlyMosaic` 只应用马赛克；`SelectionModel.isLocked`；`OverlayKeyMap` 的 `⌘Z` / `⇧⌘Z`；设置读写与非法值回退。

手动验收清单（实现计划最后一个任务逐条列出，面向非开发者）：九种工具逐个试、`Shift` 约束、颜色 / 粗细切换与记忆、文字工具的中文输入与换行、撤销 / 重做按钮与快捷键、取消键三级、选区锁定与解除、工具条 / 样式栏在屏幕边缘的位置、复制 / 保存 / 贴图带标注且 Retina 下清晰、识别文字不读马赛克下的内容且不受箭头等干扰、多显示器、截图结束后内存回落。

## 6. 实现阶段的细化（写计划并编译验证时确定）

1. `AnnotationRenderer.draw` 的实际签名为 `draw(_:in:selectionSize:baseImage:cache:)`：调用方先把上下文变换到选区内坐标（`flatten` 负责按像素倍数放大）；正在画的那一个标注由第二次、不走缓存的调用绘制。
2. 样式栏位置：放在工具条**背向选区**的一侧（工具条在选区下方 → 样式栏在工具条下方；否则在上方），放不下则翻到另一侧。纯函数 `ToolbarPlacement.styleBarOrigin`（已测）。
3. 正在输入文字时点击别处：只完成文字输入，这次点击不会再开始一个新标注。
4. 正在输入文字时：工具条的「撤销」按钮 = 丢弃当前输入；`⌘Z` / `⇧⌘Z` 交给输入框；`⌘X/C/V/A` 由 `OverlayPanel` 转发给输入框。
5. 文字输入框不自动折行（回车才换行），保证屏幕上看到的和导出的一致；超出选区的部分被裁掉。
6. 工具顺序以 §2.1 的工具条示意为准：方框、椭圆、箭头、直线、画笔、荧光笔、文字、马赛克、序号。
7. 新增的小单元：`AnnotationStyle`（颜色、档位、荧光笔 40% 不透明度）、`MosaicCache`（只活在一次截图会话内）、`CancelLevel` / `OverlayCancel`（取消键三级，已测）、`AnnotationStyleBar`、`ScreenshotSettings.annotation`、`ScreenshotActions.perform(_:result:)` 与 `followUpMessage`、`CaptureResult.annotationsDropped`。
8. `OverlayView`：`cancelSelection()` 改为 `handleCancel()`；`resetSelection()` 同时清空标注和马赛克缓存；初始化参数增加定格图、像素倍数和 `AnnotationSettings`。
9. 马赛克：矩形被切成 round(宽/方块) × round(高/方块) 个方块，正好铺满，不留半块。
10. 箭头的线身在距箭尖约 0.9 × 箭头深度处停止，避免线头从箭尖露出来。
11. 需要真机确认的主要风险：中文输入法的候选词窗口能否显示在全屏遮罩之上（验收清单第 8 条）。
