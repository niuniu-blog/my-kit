# MyKit

放在 Mac 菜单栏里的个人工具箱：**剪切板历史、截图（标注 / 文字识别 / 翻译 / 贴图）、系统监控（CPU / 内存 / 网速）、卸载软件**。

- 全部功能都在本机完成，**不联网**，没有任何第三方依赖，数据只保存在你自己的电脑上。
- 常驻开销很小：空闲时约占单个核心 1% 以下的 CPU，内存约 60–70 MB；程序本体 1.4 MB。
- 需要 **Apple 芯片（M 系列）的 Mac，macOS 14 或更新**。不支持 Intel 芯片的 Mac。

## 功能

| 模块 | 怎么呼出 | 能做什么 |
|---|---|---|
| 剪切板历史 | 快速按两下 `Option` | 最近 7 天复制过的文字，打字即搜索（中文也行），回车直接粘贴回原来的位置；每条记录带来源 App 的图标；密码管理器复制的密码不会被记录 |
| 截图 | `⇧⌘A` | 鼠标移到窗口上自动识别边框，单击选中整个窗口，或拖出任意区域；复制 / 保存 PNG / 识别文字 / 贴在屏幕上；九种标注工具 + 撤销重做 |
| 文字识别与翻译 | 截图工具条 →「识别文字」 | 中英文离线识别（系统 Vision）；可勾选「翻译成中文」（系统翻译框架，英 → 中，离线） |
| 系统监控 | 一直显示在菜单栏 | 两行小字：CPU / 内存 / 下载 / 上传；点开菜单看最占 CPU、内存的 5 个软件；可收起 |
| 卸载软件 | 菜单 →「卸载软件…」 | 找出软件本体和散落各处的残留文件（含隐藏文件），过目确认后**移到废纸篓**，可从废纸篓恢复 |

所有快捷键都可以在偏好设置里修改，改完立即生效。

## 安装

1. 到 [Releases](../../releases) 下载最新的 `MyKit-x.y.z.dmg`。
2. 双击打开，把 **MyKit** 拖到旁边的 **Applications（应用程序）** 文件夹里。
3. 到"应用程序"里打开 MyKit。屏幕右上角会出现它的图标（三层叠起来的方块）。

### 第一次打开会被系统拦住 —— 这是正常的

MyKit 是个人制作的软件，没有向苹果付费做开发者认证，所以 macOS 第一次不让直接打开。放行一次即可，以后不会再问：

- **macOS 15 或更新**：双击 MyKit，提示"无法打开"时点「完成」（不要点"移到废纸篓"）→ 打开 **系统设置 → 隐私与安全性**，往下翻到"安全性"一栏 → 找到"已阻止 MyKit…"，点「仍要打开」，输入电脑密码。
- **macOS 14**：在"应用程序"里**右键**点 MyKit →「打开」→ 在弹出的窗口里再点「打开」。
- 上面都不行的话，打开"终端"，粘贴这一行并回车，然后再双击打开：
  ```bash
  xattr -dr com.apple.quarantine /Applications/MyKit.app
  ```

### 授权（每项只需要一次）

| 授权 | 什么时候要 | 怎么开 |
|---|---|---|
| **辅助功能**（必须） | 第一次启动 | 引导窗口 →「打开系统设置」→ 在列表里打开 MyKit 的开关。双击 Option、截图快捷键、自动粘贴都靠它 |
| **屏幕录制** | 第一次截图 | 引导窗口 →「打开系统设置」→「录屏与系统录音」里打开 MyKit → 回到引导窗口点「重新启动 MyKit」（这项授权要重启后才生效） |
| App 管理 / 控制访达 | 第一次卸载软件 | 系统弹窗时点「允许」。拒绝了的话到 隐私与安全性 → App 管理 / 自动化 里打开 |

右上角图标变成 ⚠️ 三角形 = 辅助功能授权丢失了，重新打开开关即可。系统偶尔会问"是否继续允许 MyKit 录制屏幕"，点「继续允许」。

## 使用说明

### 剪切板历史

| 操作 | 效果 |
|---|---|
| 快速按两下 `Option` | 打开 / 关闭面板（面板不会抢走当前 App 的焦点） |
| 直接打字 | 搜索 |
| `↑` `↓` | 选择 |
| `↩` | 粘贴到刚才正在用的 App |
| `⌘1` – `⌘9` | 直接粘贴第 1–9 条 |
| `⌘⌫` | 删除选中的记录 |
| `Esc` / 点击面板外 | 关闭面板 |

菜单里的「暂停记录」可以临时停止记录（图标变灰）。保留天数（默认 7 天，1–90）和「清空历史」在偏好设置里。

### 截图

按 `⇧⌘A`（或菜单 →「截图」），屏幕定格并变暗：

- 鼠标移到某个窗口上，它会变亮，**单击**即选中整个窗口；或者**按住拖动**框出任意区域。
- 选好后可以拖 8 个小方块改大小、在选区里拖动改位置。选区左上角显示尺寸。

| 工具条按钮 | 键盘 | 效果 |
|---|---|---|
| 复制 | `↩` / `⌘C` / 双击选区 | 图片进剪切板 |
| 保存 | `⌘S` | 存成 PNG（默认桌面，可在偏好设置里改） |
| 识别文字 | `⌘R` | 截图画面**不关闭**，结果面板出现在选区旁边，文字可编辑、可只选一部分，全文已自动复制；打了马赛克的地方不会被识别 |
| 贴图 | `⌘T` | 截图原地浮在所有窗口上面 |
| 退出截图 ✕ | `Esc` | 按一下就退出（正在往标注里打字时，第一下只是完成输入） |
| — | 右键 | 逐级取消：完成打字 → 取消工具 → 清除选区回到框选状态 → 退出。想重新框选但不想退出时用 |

截图进行中再按一次 `⇧⌘A` 也能直接退出。

**标注**：工具条左边一排是标注工具，点一下选中、再点取消；选中后可选 6 种颜色和细 / 中 / 粗三档（会记住上次的选择）。

| 工具 | 用法 |
|---|---|
| 方框 / 椭圆 | 拖出形状；按住 `Shift` 画正方形 / 正圆 |
| 箭头 / 直线 | 起点拖到终点；按住 `Shift` 吸附到水平、垂直或 45° |
| 画笔 | 随手涂画 |
| 荧光笔 | 半透明粗线；按住 `Shift` 画直线 |
| 文字 | 点一下出现输入框，直接打字（支持中文输入法，回车换行），点别处或 `Esc` 完成 |
| 马赛克 | 拖出矩形，遮手机号、密码等 |
| 序号 | 每点一下放一个 ①②③…，自动递增 |

`⌘Z` 撤销、`⇧⌘Z` 重做。画好的标注不能再选中移动，撤销重画即可。有标注时选区会锁定，全部撤销后才能再调整选区。复制 / 保存 / 贴图得到的图都带标注。

**翻译成中文**：识别结果面板上勾选「翻译成中文」，下半部分显示译文（可「复制译文」），以后每次识别完自动翻译，直到取消勾选。只翻译英文。用的是 macOS 自带的翻译（离线、免费），需要 macOS 15 或更新。第一次使用时系统会提示下载英译中语言包；如果没看到提示，到 系统设置 → 通用 → 语言与地区 → 翻译语言 里下载「英语」和「简体中文」。

**贴图**：拖动移动；滚轮 / 触控板双指滑动缩放，也可以双指捏合；双击关闭；右键有 复制 / 保存 / 识别文字 / 关闭 / 关闭全部贴图。菜单里有「关闭所有贴图」。

### 系统监控

菜单栏上是两行小字：第一行 CPU 和下载速度（↓），第二行内存和上传速度（↑），例如 `CPU 12% ↓1.2M` / `内存 63% ↑ 56K`（K = KB/s，M = MB/s）。某一项达到 85% 时数字变红。

- 点开菜单：CPU（用户 / 系统）、内存（已用 / 总量）、网络，各列出最占资源的 5 个软件（辅助进程合并到所属软件；系统自己的后台进程读不到，不参与排行）。排行只在菜单打开时统计，关上就停。
- 菜单最上面的「收起菜单栏数字」可以把右上角收成只剩图标（此时后台也不采样）；再点「展开菜单栏数字」恢复。
- 网速只统计真正联网的网卡（Wi-Fi、有线、热点），本机代理和 VPN 的虚拟网卡不重复计算。可在偏好设置里关掉网速显示，或把刷新间隔改成 1 / 2 / 5 秒。
- 单个软件的 CPU 百分比与"活动监视器"口径一致：占满一个核心 = 100%，可超过 100%。菜单里有「打开活动监视器…」；MyKit 不提供"结束进程"。

### 卸载软件

菜单 →「卸载软件…」：

1. 左边选一个软件（可搜索、按名称 / 大小排序），或把 `.app` 从访达拖进窗口。系统自带的软件和 MyKit 自己不可卸载。
2. 右边是要移走的清单，分三组：**确定相关**（默认勾选：软件本体、名字里带该软件独有标识的数据 / 缓存 / 偏好设置 / 容器 / 日志 / 启动项……）、**可能相关**（默认不勾选：只是同名或名字沾边的，比如主目录下的隐藏文件夹，请自己判断）、**需要管理员密码**（系统级目录里的后台服务、安装记录等）。「全选」一键勾上所有项，「在访达中显示」可以先看看它是什么。
3. 点「移到废纸篓」→ 确认 → 完成后显示移走了多少项、释放了多少空间；没移走的逐条写明原因。软件正在运行时会先问你要不要退出它（只正常退出，不强制结束）。

安全规则：**只移到废纸篓，没有任何永久删除**（后悔了到废纸篓里「放回原处」）；每一项移走前都会再检查一遍，只有软件本体和固定位置下的直接子项才会被移动；需要管理员权限的项交给访达执行（系统弹密码框），MyKit 不接触密码。

### 偏好设置

菜单 →「偏好设置…」（`⌘,`）：开机自启；剪切板保留天数、呼出方式（双击 Option / Control / Command）、清空历史；截图快捷键（点一下按钮再按下新组合键；普通键必须带 `⌘` `⌃` `⌥` 之一，`F1`–`F12` 可单独用）、保存位置；系统监控的显示、网速、刷新间隔。

`⇧⌘A` 与钉钉的默认截图键相同、在访达 / Chrome 里也另有用途；冲突时在 MyKit 里换一个，或关掉那边的快捷键。

## 数据与隐私

- 剪切板历史：`~/Library/Application Support/MyKit/clipboard.sqlite`，只在本机。
- 截图只有点「保存」时才写文件；文字识别、翻译在本机完成（翻译语言包首次需联网下载一次）。
- 系统监控只在内存里保留最近一次读数；卸载软件不保存任何记录。
- MyKit 自己的代码里没有任何联网调用，也不含第三方库。

卸载 MyKit：菜单 →「退出 MyKit」，把"应用程序"里的 MyKit 拖进废纸篓；想连数据一起清掉，删除 `~/Library/Application Support/MyKit`。

## 从源码构建

要求：Apple 芯片的 Mac、macOS 14+、Xcode Command Line Tools（`xcode-select --install`），**不需要完整的 Xcode**。

```bash
scripts/create-dev-cert.sh   # 只需一次：创建本地签名证书（固定证书 → 重新编译后系统授权不会失效）
scripts/build-app.sh         # 编译并组装 build/MyKit.app
scripts/install.sh           # 安装到 /Applications 并启动
scripts/test.sh              # 跑全部单元测试（Swift Testing）
scripts/make-dmg.sh          # 制作安装包 build/MyKit-<版本>.dmg
```

版本号在 `Resources/Info.plist` 的 `CFBundleShortVersionString`。安装包用的是本地自签名证书、未经苹果公证，所以别人第一次打开会被拦一次（见上文）；要免掉这一步需要 Apple Developer 账号并做公证，工程结构不用改。

### 项目结构

```
Sources/
  Core/                 模块协议、全局快捷键、浮动面板、粘贴、权限、Toast、菜单栏图片
  ClipboardModule/      剪切板监听、SQLite + FTS5 存储、面板
  ScreenshotModule/     截屏、遮罩与选区、标注、OCR、翻译、贴图
  SystemMonitorModule/  CPU / 内存 / 网速读取、进程排行、菜单视图
  UninstallerModule/    软件列表、残留扫描、移到废纸篓
  MyKit/                外壳：菜单栏、偏好设置、授权引导
Tests/                  各模块的单元测试（500+，不依赖真实权限、不碰真实文件）
docs/superpowers/       每个模块的设计文档与实现计划
scripts/                构建、测试、签名、打包
```

纯 Swift（AppKit + SwiftUI），全部使用系统框架：SQLite3 / FTS5、ScreenCaptureKit、Vision、Translation、ServiceManagement。
