# MyKit 设计文档：代理终端模块（一键开多个 iTerm2 分屏并校验出口 IP）

日期：2026-11-02
状态：已实现（分支 `feat/proxy-terminals`），核对通过后启动 Claude Code
前置：外壳、剪切板、截图、系统监控、卸载器均已合并到 main

## 1. 目标与范围

在 MyKit 菜单里点一下，让 iTerm2 打开一个窗口并切成 N 块终端；每块自动执行 `proxy` 和 `curl ip.sb`，MyKit 读出每块显示的出口 IP，与小窗口里这套组合预设的 IP 比对：对的进入"下一步"，不对的标红停下。

### 已确认的决策

| 项 | 决策 |
|---|---|
| 窗口样子 | 一个 iTerm2 窗口切成几块并排显示（与 Claude Code 在 iTerm2 里多助手分屏一样），不是多个标签页 |
| 设置方式 | 点菜单项先弹一个「打开代理终端」小窗口：一行一个终端，每行选一个文件夹；终端数量 = 行数。设置自动记住 |
| 组合 | 可以存好几套（如「工作」「个人」），每套有名字、自己的文件夹列表和预期 IP |
| 标题 | 每块的标题显示所在文件夹的名字 |
| IP 不对时 | 那一块标红并停下，MyKit 提示哪几块不对；其余对的照常继续 |
| 下一步 | （2026-11-02 定）核对通过的块倒计时 5 秒（可按 Ctrl+C 取消）后自动启动 Claude Code；核对失败（IP 不对 / 没拿到 / 超时 / 被关掉）的块**绝不执行**。启动前在 shell 里再查一次出口 IP，与核对结果不一致也不启动 |

### 本机情况（2026-11-02 查过）

- iTerm2 已安装在 `/Applications/iTerm.app`。
- `proxy` 是用户 `~/.zshrc` 第 146 行的别名：设置 `http_proxy` / `https_proxy` = `http://127.0.0.1:7892`（并设置 no_proxy），然后打印"终端代理已开启…"。因为是别名，必须在 iTerm2 的交互式 shell 里输入执行，MyKit 自己起子进程跑不到它 —— 这也正是要在终端里执行的原因。

### 不做（第一期）

支持 Terminal.app / 其他终端、同一套组合里每块各自不同的预期 IP、单独的快捷键、自动重试、校验通过后的具体动作。

## 2. 用户可见的行为

### 2.1 菜单

菜单里新增一项「打开代理终端…」，点击弹出 2.2 的小窗口（不再有偏好设置页）。

### 2.2「打开代理终端」小窗口

```
┌─ 打开代理终端 ─────────────────────────────┐
│ 组合：[ 工作 ▾ ]  [新建] [改名] [删除]       │
│ 预期 IP：[ 1.2.3.4            ]              │
│                                            │
│ 1  ~/my              [选文件夹…]  [−]       │
│ 2  ~/work/api        [选文件夹…]  [−]       │
│ 3  ~/work/web        [选文件夹…]  [−]       │
│ [+ 加一个终端]                               │
│                                            │
│                       [取消]  [打开 ↩]      │
└────────────────────────────────────────────┘
```

- 打开时选中上次用的那套组合；内容没变化直接回车即可打开。
- 每套组合各自保存：名字、预期 IP、文件夹列表（1–9 行，同一个文件夹可以出现多次）。任何修改立即保存，不需要单独点"保存"。
- 「新建」：起个名字，内容先复制当前这套，再改。「删除」需要确认；只剩一套时不能删。第一次使用时自动建一套叫「默认」、一行（主目录）、IP 为空。
- 选文件夹：点「选文件夹…」弹系统的选文件夹框；也可以把文件夹从访达拖到这一行上。路径显示时用 `~` 缩写主目录。
- 「打开」按钮在以下情况不可点，并在出问题的地方显示红字：IP 没填或格式不对（IPv4 / IPv6）、某行文件夹不存在（比如被删了或移动了）。
- 点「打开」后小窗口关闭，进入 2.3。

### 2.3 打开之后

1. iTerm2 新开一个窗口，切成 N 块（N = 行数）。布局按网格：每行最多 2 块（1 = 整窗；2 = 左右；3 = 上 2 下 1；4 = 2×2；以此类推）。
2. 每块的标题是文件夹名（如 `api`）；同名的加序号区分（`api`、`api (2)`）。
3. 每块依次输入两行：`export DISABLE_AUTO_TITLE=true; printf '\033]0;%s\007' '文件夹名'; cd -- '文件夹'`（关掉 oh-my-zsh 自动改标题、先把标题设成文件夹名，再进文件夹），然后 `proxy; curl -s --max-time 10 ip.sb; echo; echo "MYKIT-END-$((a+b))"`。
4. MyKit 在后台读每块的屏幕内容，找出 curl 打印的 IP，与这套组合的预期 IP 比对：
   - 一致：标题改为 `api ✅ 1.2.3.4`，并输入 `for i in 5 4 3 2 1; do printf '\r✅ IP 核对通过，%s 秒后启动 claude（按 Ctrl+C 取消）' $i; sleep 1; done; echo; if [ "$(curl -s --max-time 10 ip.sb)" = '1.2.3.4' ]; then CLAUDE_CODE_DISABLE_TERMINAL_TITLE=1 claude; else echo '❌ 出口 IP 和核对时不一致，已阻止启动 claude'; fi`（倒计时 5 秒，Ctrl+C 整行取消；倒计时结束再核对一次才启动；关掉 Claude Code 改终端标题，标题保持文件夹名）。
   - 不一致 / 15 秒内没拿到 IP（代理没开、网络不通等）：该块背景染成淡红色、标题改为 `api ❌ 5.6.7.8` 或 `api ❌ 超时`，不再往下走。
5. 全部出结果后，MyKit 弹一条提示（沿用现有 Toast）：`3 个终端：2 个 IP 正确，web 不对（实际 5.6.7.8）`。

### 2.3 首次使用

macOS 会弹窗"MyKit 想要控制 iTerm2"，点「好」即可。若用户点了「不允许」，MyKit 提示去「系统设置 → 隐私与安全性 → 自动化」里打开 MyKit 对 iTerm2 的开关（AppleScript 错误码 -1743，与卸载器对访达的处理方式一致）。

## 3. 技术方案

- 2026-11-02 真机实测：iTerm2 3.7.6 切出的块会自动排成一样大（不需要再点「平均排列拆分窗格」）；oh-my-zsh 会在每条命令执行前把标题改成命令本身（出现过标题 `export`），所以第一行里关掉自动改标题并用 OSC 0 设标题，检查期间每 0.5 秒还会用 AppleScript 再设一次。
- 通过 AppleScript（`NSAppleScript`，与卸载器的 `FinderTrasher` 同一机制）控制 iTerm2：`create window with default profile`，对 session 用 `split vertically / horizontally with default profile` 切出网格，`write text` 输入命令，`set name` 改标题，`set background color` 染红。
- 读取结果：轮询每个 session 的 `contents`（屏幕文本），每 0.5 秒一次，最多 15 秒。为了不把命令行本身误当结果，curl 之后再输出一个结束标记：
  `echo "MYKIT-END-$((a+b))"`（a+b = 每次随机的 6 位数）—— 命令行上显示的是算式，只有真正执行后屏幕上才出现算好的数字；只解析结束标记之前、命令行之后的那几行。
- IP 解析与比对放在纯函数里（不依赖 iTerm2，可单元测试）：从文本里提取 IPv4 / IPv6，比对时规范化（去空白、IPv6 统一小写和压缩写法）。
- "下一步"接口：`protocol PassAction { func run(on session: TerminalSessionRef) }`，第一期注册一个空实现；用户定了以后只替换这里。
- Info.plist 的 `NSAppleEventsUsageDescription` 改为同时说明访达和 iTerm2 两个用途。
- 组合保存在 UserDefaults（JSON 编码的数组 + 上次使用的组合 id），与其他模块的设置方式一致。
- 新模块目录 `Sources/ProxyTerminalModule/`，按现有模块方式在 `AppDelegate` 注册，菜单顺序排在卸载器之后。

## 4. 测试

- 单元测试：IP 提取（含 curl 报错文本、空输出、IPv6）、比对规范化、网格布局计算（N=1…9 每块的切分方向）、同名文件夹标题加序号、组合的增删改与持久化、打开按钮的可用条件、结束标记之后的截取逻辑。
- 真机验证（只能人工）：自动化授权弹窗、文件夹拖入、N=1/4/9 的分屏样子、代理关掉时标红、拒绝授权后的提示。
