MyKit 安装说明
==============

MyKit 是一个放在屏幕右上角的小工具箱：剪切板历史、截图（标注 / 文字识别 / 翻译 / 贴图）、
系统监控（CPU / 内存 / 网速）、卸载软件。所有数据只保存在你自己的电脑上，不联网。

需要：Apple 芯片（M 系列）的 Mac，macOS 14 或更新的系统。不支持 Intel 芯片的 Mac。


一、安装

把 MyKit 拖到旁边的 Applications（应用程序）文件夹里，然后到"应用程序"里打开它。


二、第一次打开会被系统拦住 —— 这是正常的

MyKit 是个人制作的软件，没有向苹果付费做开发者认证，所以 macOS 第一次不让直接打开。
只需要放行一次，以后就正常了：

  macOS 15 或更新：
    1. 双击 MyKit，提示"无法打开"，点"完成"（不要点"移到废纸篓"）
    2. 打开 系统设置 → 隐私与安全性，往下翻到"安全性"一栏
    3. 找到"已阻止 MyKit…"那一行，点"仍要打开"，输入电脑密码
    4. 再次确认"仍要打开"

  macOS 14：
    在"应用程序"里右键点 MyKit → 打开 → 在弹出的窗口里再点"打开"

  如果上面的办法不行：打开"终端"，粘贴下面这一行并回车，然后再双击打开 MyKit
    xattr -dr com.apple.quarantine /Applications/MyKit.app


三、授权（每项只需要一次）

  辅助功能（必须）—— 双击 Option 呼出剪切板、截图快捷键、自动粘贴都靠它
    第一次启动会弹出引导窗口 → 点"打开系统设置" → 在列表里打开 MyKit 的开关

  屏幕录制（用截图时才需要）
    第一次按截图快捷键会弹出引导 → 到系统设置里打开 MyKit 的开关 → 回到引导窗口点"重新启动 MyKit"

  系统偶尔会问"是否继续允许 MyKit 录制屏幕"，点"继续允许"即可。


四、怎么用

  看右上角的 MyKit 图标（三层叠起来的方块），左键或右键点它都会弹出菜单。

  双击 Option ............ 剪切板历史（打字搜索，回车粘贴）
  ⇧⌘A .................... 截图（框选或点窗口；可以标注、识别文字、翻译、贴在屏幕上）
  菜单 → 卸载软件… ....... 连同残留文件一起移到废纸篓（可以从废纸篓恢复）
  菜单 → 偏好设置… ....... 改快捷键、保留天数、开机自启、监控显示等

  微信和钉钉自带的截图快捷键如果和 ⇧⌘A 冲突，到它们的设置里关掉，或者在 MyKit 的偏好设置里换一个。


五、卸载 MyKit

  点右上角图标 → 退出 MyKit，然后把"应用程序"里的 MyKit 拖进废纸篓。
  想连数据一起清掉：删除 ~/Library/Application Support/MyKit 这个文件夹（剪切板历史在里面）。
